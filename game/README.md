# Pokémon Arena HD-2D

`../pokeData` と `../pokeSprite`、`../pokeAnim` のデータで動く、見下ろし型のリアルタイム対戦ゲームです。

## 起動

- **おすすめ:** `pokemon_arena_sample/ゲーム起動.command` をダブルクリックします。ローカルサーバーが立ち上がり、ブラウザで開きます。
- `game/index.html` を直接開いても遊べます。全ポケモンがスプライトシート（`pokeAnim`）を持つので、そのままアニメーションします（GIF の直接表示は予備で、http で開いたときだけ動きます）。

## 操作

| 操作 | キー |
|---|---|
| 移動 | W A S D / 矢印 |
| 技1〜4 | Z X C V（または 1〜4） |
| 回避（無敵ダッシュ） | Space |
| メガシンカ / 元に戻る | M（メガ進化が複数あるポケモンは押すたびに切り替え） |
| キョダイマックス / 元に戻る | G |

CPU が操作するポケモン（観戦モードの両チーム、プレイモードの相手）は、メガシンカ・キョダイマックスできる姿なら登場から数秒後（HP が半分を切るともっと早く）に自分で変身します。1 体につき 1 回で、メガとキョダイの両方があるときはどちらかをランダムに選びます。練習モード（CPU の攻撃なし）では変身しません（`js/ai.js` の `formIntent`）。
| 交代 | Q |
| 色違い ⇄ 通常の色（場に出ているポケモン） | K（観戦中は L で相手側も）。HP・技の再使用時間・姿はそのまま。色違いの絵が無い姿では切り替わらない |
| CPUの攻撃 あり／なし（練習モード）の切替 | T（メニューの「CPUの攻撃」でも選べます） |
| 一時停止 | Esc |

## データの使われ方

- **ポケモン:** `pokeData.js` の全1216体（メガシンカ・リージョン・キョダイマックスを含む）を選べます。種族値からLv.50の能力値を計算します。
- **技:** 各ポケモンの覚える技から、タイプ一致・威力・物理/特殊の適性を見て4つを自動で選びます。技の形（飛び道具・ビーム・放射・雷・範囲・突進・補助）は技ごとに決まります。
- **能力差:** `pokeData` の値をそのまま動きに反映します（`js/data.js` の `profileOf` / `mightOf`）。
  - **体格:** 高さ（`height`）で画面上の大きさと当たり判定が決まります（ピカチュウ < リザードン < イワーク）。大きいポケモンほど突進・放射・周囲攻撃の届く距離が伸びます。キョダイマックスは元の姿の1.5倍です。
  - **重さ:** 重さ（`weight`）が重いほど吹き飛ばされにくく、突進で相手を大きく押し返し、ぶつかり合いでも押し負けません。動き出しと止まりは少し重くなります。
  - **素早さ:** 素早さが高いほど移動が速く、技・回避の再使用までの時間が短く、ビームのチャージや雷・範囲技の発動までの溜めも短くなります（ツボツボ ≈ 0.6倍 〜 レジエレキ ≈ 1.5倍のテンポ）。弾や突進も速くなり、アニメーションもきびきびします。
  - **攻撃・特攻:** ダメージ計算に加えて、攻撃（物理技）/ 特攻（特殊技）が高いほど技が大きく遠くまで届きます（弾の大きさと射程・爆風、ビームの太さと長さ、放射の射程と広がり、雷・範囲技の半径）。ノックバックと画面の揺れも強くなります。CPUもこの射程に合わせて間合いを取ります。
- **ダメージ:** 本家のダメージ計算式とタイプ相性（`typeMatchups.defenseMultipliers`）を使い、リアルタイム向けに縮小しています。
- **スプライト:** `../pokeAnim`（PMD SpriteCollab のスプライトシートと、絵の無いポケモン用に GIF から作ったシート。`tools/build-anim.js` で生成）を使います。
  - 8方向（下・右下・右・右上・上・左上・左・左下）の向きごとに、待機（Idle）と移動（Walk）で手足が動きます。
  - 技ごとに専用モーションを再生し、モーションの「当たりフレーム」で技が出ます（突進＝Attack、切り裂き系・大技＝Strike、口から吐く技・撃ち出す技＝Shoot、特殊技＝SpAttack、溜め＝Charge）。被弾で Hurt、ひんしで Faint を再生します。シートに無いモーションは近いもので代用します（`js/fighter.js` の `ANIM_CHAIN`）。
  - 画面上の大きさはシートの体の高さを `pokeData` の高さに合わせます（ドット絵は拡大時もぼかしません）。当たり判定の大きさは従来と同じです。
  - 1216体すべてにシートがあります。1072体は PMD SpriteCollab の絵、残りの144体（SpriteCollab に絵が無い、または静止画1枚だけのもの。メガシンカ56・キョダイマックス34・第5〜9世代とリージョンの一部54）は `pokeSprite` の GIF から `tools/build-gif-anim.js` で作ったシートです（manifest で `"source": "gif-pixel"`）。GIF の絵はそのままではなく、`tools/pixelize.js` で PMD 風のドット絵（PMD と同じ体の高さ・約 12 色のフラットなパレット・1px の黒い輪郭）に描き直してあるので、PMD の絵と並んでも同じ画素の大きさ・同じ画風に見えます。
  - GIF 由来のシートはプロポーションを変えません（変形なし）。待機は GIF 本来のコマ（技のエフェクトが描き込まれた GIF では、エフェクトの無いコマだけ）、各技は GIF のコマを選び、踏み込み・反動・浮き上がり・沈み込みなどの整数ピクセルの平行移動と白フラッシュを付けて作っています。向きは front / front-reverse / back / back-reverse の 4 枚を 8 方向に割り当てます。
  - GIF 由来のシートの調整（技ごとのコマ・当たりフレーム・踏み込み量・待機のコマ）は `../tools/gif-anim-overrides/*.json` に書き、`node tools/build-gif-anim.js --only <ロスターid> --review <dir>` で作り直して確認します（書式は同フォルダの README.md）。ドット絵の見た目（`pixelHeight`・`colors`・`innerLines`・`lineWeight`・`paletteFrom`・`speckSize`・`darkLift` など）も同じファイルで 1 体ずつ調整でき、`--pixel-review <dir>` の確認シートで基本種の PMD 絵と見比べられます。使われた値は manifest の `pixel` に記録されます。
  - シートが読めなかったときは従来どおり `pokeSprite` の GIF を向きに応じて切り替えて表示します。
  - メニューのアイコンは `pokeSprite` の png のままです。
- **色違い:** メニューのスロットの ✨ でそのポケモンを色違いにできます。メニューの「色違いの確率」（出ない / 1/16 / 1/4 / 1/2 / 全員）は、✨ で指定していないポケモンがバトル開始時に色違いになる確率です（両チームとも）。`pokeSprite/manifest.js` に色違い一式（`frontShinyPng` など）があるフォームだけが対象で、無い姿（Z-A のメガシンカの一部）は ✨ が押せません。
  - アイコン・HUD・GIF は `pokeSprite` の `*-shiny.*` をそのまま使います。戦闘のスプライトシート（`pokeAnim`）には色違い版が無いので、読み込み時に `front.png` → `front-shiny.png` の色の対応表（色ごとの色相のずれ・彩度と明度の比率。出現割合の近い色どうしを対応づけます）をシートの全フレームに当てはめて作ります（`js/sprites.js` の `recolour`）。PMD の絵は配色が本家と違うことがあるので、近似です。
  - この色置換はピクセルを読む必要があるため、http で開いたとき（`ゲーム起動.command`）だけ働きます。`file://` で直接開いた場合は、アイコンと名前の ✨ だけ色違いになり、戦闘の絵は通常の色のままです。
  - 色違いのポケモンは登場時に金色のきらめきが出て、名前に ✨ が付きます。メガシンカ・キョダイマックスしても色違いのままです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `js/data.js` | ロスター構築・技選択・ダメージ計算 |
| `js/sprites.js` | スプライト読み込み・GIFデコード・PMDシートのフレーム切り出し |
| `js/arenas.js` | 5種類のフィールドを手続き的にドット絵で描画 |
| `js/render.js` | HD-2D描画（光の筋・ブルーム・被写界深度ぼかし・ビネット） |
| `js/moves.js` | 技の挙動と当たり判定、技ごとのモーション割り当て |
| `js/fighter.js` / `js/ai.js` / `js/battle.js` | ポケモン・CPU・対戦進行 |
| `js/effects.js` / `js/hud.js` / `js/menu.js` / `js/main.js` | エフェクト・HUD・メニュー・起動 |
| `../tools/build-anim.js` | `pokeAnim` の生成（SpriteCollab から各ロスターに合うシートを選んでコピー。個別指定は `../tools/anim-overrides/*.json`）。最後に `build-gif-anim.js` も実行 |
| `../tools/build-gif-anim.js` | PMD の絵が無いロスターのシートを `pokeSprite` の GIF から生成（個別調整は `../tools/gif-anim-overrides/*.json`） |
| `../tools/build-pmd-anim.js` | 1 体ずつ、`pokeSprite` の GIF から「不思議のダンジョン 赤の救助隊（GBA）」の画風（ROM 実測の体高・15 色・黒輪郭）と動き（ROM の ax アニメ表をそのまま読む）でシートを生成。`--install` で今の gen フォルダ配置の pokeAnim と manifest を更新（ノウハウは `../tools/README-pmd-anim.md`） |

## テスト用の起動オプション

メニューを飛ばして対戦を始められます。

```
index.html?autostart=charizard+venusaur,pikachu&arena=meadow&mode=watch&level=0.8
```

- `autostart`: ポケモンの slug。`+` で同じチーム、`,` で左右のチームを区切ります。slug の後ろに `*` を付けると色違いになります（例 `charizard*`）。`shiny=0.25` のように付けると、残りのポケモンがその確率で色違いになります（省略時 0）。
- `arena`: フィールドの id（省略時 `meadow`）。`mode`: `watch`（CPU同士、省略時）または `play`。`level`: CPUの強さ（0.55 / 0.8 / 1）。
- 対戦中はブラウザのコンソールで `ArenaDebug.battle` から状態を見られます。
