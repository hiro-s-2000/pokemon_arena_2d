# メガ・キョダイの元GIF高精細版

前回の基本種＋パーツ方式では、巨大な花・翼・砲塔と体型の再現が不足したため、
7形態について元GIFの全身画素を保持する比較版へ変更した。
これは新しい角度の描き起こしではなく、正背面からの投影近似である。

```sh
node tools/build-form-source-detail.js
node tools/build-eight-direction-roster.js --publish-only
node tools/validate-form-source-detail.js
node tools/validate-eight-direction-assets.js
```

`--id <id>`で1形態だけ再生成、`--resume`で生成済みv2を飛ばす。
通常9体は変更しない。前回7形態のシートは`form-pmd-v1/`へ保存し、
メイン画面の「描画方式」で前回PMD版と切り替えられる。

## 保持するもの／近似するもの

- 全身の輪郭、顔、翼膜、花と葉、甲羅、砲塔、炎は元GIFの画素から直接描画。
  新たな色を作らず、減色しない。front/back PNGはGIFと違う姿勢の場合があるため、
  実際に使用するGIFのフレームを直接確認して採用する。
- キャラクターの最大寸法はメガ約180px、キョダイ約194px。セル320×320、足元240。
  動きで変化するため各コマの実寸は異なる。単なるPMD絵の拡大ではない。
- 斜めの4配置は元の正背面および反転。残り4配置は曲面の横方向変形と傾きによる近似。
  真正面・真横の顔や隠れた部位を復元できたとは主張しない。
- 待機60、歩行48、攻撃36、被弾24、倒れる48コマ。
  元GIFのコマ、脚領域の軽い変形、方向に応じた移動・回転を使用する。
  専用ポーズや閉じ目は描き足していない。倒れた最終コマは保持する。

`quality-comparison.png`は元GIF／前回PMD／今回版の並び。
全7形態をまとめた`form-quality-comparison.png`は検証スクリプトが作る。
`directionSources`に各方向の元GIF、反転、近似角度を記録する。

検証：入力ハッシュ、PNG寸法、全コマの余白、元GIF以外の色を追加していないこと、
通常9体の45シートが不変であることを確認する。
